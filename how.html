The Pipeline

Four steps to the truth

01
Ingestion
Upload & Pre-process
You upload media via the web dashboard, WhatsApp bot, or Telegram bot. DeepShield accepts JPG, PNG, WEBP, MP4, AVI, MOV, WAV, MP3, and OGG. Files are stored in a secure temporary buffer — never persisted to disk.
Media is validated, MIME-type checked, and if needed, converted to a normalised format. Audio files are resampled to 22050 Hz. Video files are decoded with OpenCV to extract key frames at configurable intervals.
02
Signal Extraction
Multi-modal Feature Analysis
Depending on the media type, a different forensic pipeline runs. Each module extracts a purpose-built set of signals specifically designed to expose the artifacts left by AI generation tools.
Images: Sightengine API (AI face, wrist, quality scores) + local ELA + EXIF metadata check

Video: Frame sampling → per-frame image analysis → temporal consistency scoring → suspicious-frame flagging

Voice: librosa MFCC · pitch variance · spectral flatness · formant dynamics · breathing pattern · ZCR regularity · HF energy (>8kHz)
03
Score Fusion
Weighted Confidence Fusion
Individual signal scores are fused using a weighted ensemble to produce a single synthetic probability score between 0 and 1. For voice detection, an ML ensemble (Random Forest + Gradient Boosting) is blended with rule-based scores.
Voice blend: 75% ML model score + 25% rule-based score
Image blend: 60% Sightengine API + 40% local forensic rules
Video blend: mean(frame_scores) + outlier_penalty × suspicious_frame_ratio

If the ML model has not been trained yet, the system automatically falls back to pure rule-based detection with no loss of verdict quality for typical cases.
04
Verdict & Explanation
Plain-Language Output
A threshold of 0.5 separates AUTHENTIC from SYNTHETIC verdicts. Every result includes the exact confidence score, which signals triggered, their individual weights, and a plain-language explanation in Hindi and English — designed for non-technical users.
For WhatsApp and Telegram, verdicts are formatted as concise text messages with emoji flags. For the web dashboard, users get a full breakdown including signal tables, frame-by-frame charts, and a safety advisory if synthetic content is detected.
